## Artie Simulator

The Artie Simulator is a simulated 3D environment for testing Artie without requiring access to a physical robot.

| ID | Name | Description | Milestone |
| :---: | :---: | ----- | :---: |
| AS1 | Graphical User Interface | Artie Simulator must provide a graphical user interface for viewing and controlling a simulated Artie. | Future |
| AS2 | Headless | Artie Simulator must provide a headless mechanism for training or experimenting with simulated Arties without requiring the graphical user interface to run. | Future |
| AS3 | Parallelism | Artie Simulator must allow parallelism for training and data collection. | Future |
| AS4 | Artie Model | Artie Simulator must create an Artie model based on an Artie hardware description file. | Future |
| AS5 | Physics | Artie Simulator must provide an extremely realistic physics engine, to aid in bridging the reality gap. | Future |
